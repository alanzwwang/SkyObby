# ☁️ Sky Obby: 3D Obby Adventure

**Version:** V.1.2

A 3D obby in the sky that runs right in your browser. Every time you press PLAY, it builds a brand-new obby!

## 🎮 Controls

- **Click** the game to capture the mouse
- **W A S D** to move
- **SPACE** to jump
- **R** to respawn
- **ESC** to pause

## ✨ Features

- A new obby every time you play
- Checkpoints every 5 stages
- Pets that boost your rewards
- A shop with upgrades, like a jetpack (hold SPACE in mid-air to thrust)

## 🚀 Play

Open `index.html` in any modern browser. No install needed.
